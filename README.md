# Krushi Mitra

Krushi Mitra is a platform that helps farmers discover government schemes
and check their eligibility based on their personal and agricultural details.

## Project Structure

- `data/` – Government scheme datasets
- `backend/` – FastAPI backend
- `rules/` – Eligibility rules and engine
- `frontend/` – Web interface
- `docs/` – Project reports and documentation

## Technologies

- Python
- FastAPI
- Git & GitHub
- HTML/CSS/JavaScript
